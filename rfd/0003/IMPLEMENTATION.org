#+TITLE: RFD 0003 implementation checklist
#+STARTUP: showall

Implements [[file:README.adoc][RFD 3: Reproducible workload packaging]].

* Objective

Accept one standalone binary or local OCI image layout, normalize it into one
content-addressed guest workload, and preserve exact passive replay.

* Entry gate
:PROPERTIES:
:STATUS: DONE
:END:

- [X] Complete RFD 2 and review its replay fidelity, runtime, failure bundles,
  network constraints, and next-increment recommendation.
- [X] Select one auditable static workload fixture that can exercise process
  supervision and traffic through the existing network boundary.
- [X] Capture representative standalone and minimal OCI artifacts before fixing
  parser, expansion, and cache limits.

* Phase 0 — Workload and OCI spikes
:PROPERTIES:
:STATUS: DONE
:END:

- [X] Boot and supervise an external static x86-64 Linux executable that is not
  the SimFerret agent.
- [X] Build a minimal local OCI image layout containing the same executable and
  launch it without a registry or container daemon.
- [X] Build a second minimal OCI layout whose executable is dynamically linked
  and whose interpreter and shared-library closure exist only in the image.
- [X] Select existing Rust parsing, archive, compression, and safe-filesystem
  primitives before writing custom format handling.
- [X] Apply representative base and upper layers twice and verify a stable
  normalized filesystem digest, including metadata, replacement, whiteout, and
  opaque-directory cases.
- [X] Prove that record mode can remove all live workload sources before QEMU
  starts and that replay needs only the retained raw and derived
  content-addressed closure.
- [X] Record source sizes, expanded sizes, assembly duration, initramfs growth,
  unsupported OCI constructs, and all observed nondeterminism.

* Phase 1 — Typed specification and canonical assembler
:PROPERTIES:
:STATUS: DONE
:END:

- [X] Add a strict versioned workload specification with tagged binary and OCI
  source variants, explicit non-root credentials, and a shared launch identity.
- [X] Validate static ELF architecture and derive binary content identity from
  opened bytes rather than caller claims.
- [X] Read binary and OCI source objects as bounded regular files beneath an
  opened source root, reject links and special files, and use immutable copied
  bytes for verification and assembly.
- [X] Select only the requested direct ~linux/amd64~ descriptor, require absent
  variant and OS extensions, ignore unrelated entries, and validate its manifest,
  config, ordered stored layers, and uncompressed DiffIDs independently.
- [X] Normalize OCI launch fields exactly, including Entrypoint/Cmd composition,
  environment, working directory, non-root numeric credentials, and rejected
  volume, stop-signal, group, and privileged semantics.
- [X] Implement bounded, beneath-root layer application with per-layer duplicate
  detection, legal lower-layer replacement, order-independent whiteout and
  opaque-directory semantics, and rejection of every hard link and unsupported
  file type.
- [X] Produce a canonical filesystem identity covering every guest-visible path,
  type, byte, link target, mode, owner, group, and timestamp decision.
- [X] Retain the canonical specification and complete binary or OCI selection
  evidence, manifest, config, stored layers, and DiffID relationships as a raw
  content-addressed replay closure.
- [X] Build and verify derived canonical-tree and guest-template cache entries
  that name the complete raw closure through atomic private staging.
- [X] Reject concurrent publication conflicts, corrupted cache entries, source
  mutation, missing raw evidence, path traversal, unsafe links, expansion
  limits, and partial output.

* Phase 2 — Guest process runtime
:PROPERTIES:
:STATUS: DONE
:END:

- [X] Assemble binary and OCI workloads below the same reserved initramfs root
  while keeping the PID-1 agent and tools outside it.
- [X] Materialize a fresh writable root from an immutable template for every
  invocation, synthesize deterministic ~/tmp~, ~/dev/null~, and ~/dev/zero~
  metadata, and reject overlay collisions.
- [X] In the child only, connect standard pipes, close inherited descriptors,
  chroot and change directory, clear groups, set ~no_new_privs~, drop to the
  normalized nonzero GID and UID, and exec without a shell.
- [X] Add generic versioned start, stdin-write, stdin-EOF, and fixed-SIGKILL
  termination commands with stable invocation identifiers and contiguous input
  offsets.
- [X] Emit bounded live stdout and stderr frames with invocation, stream offset,
  cross-stream sequence, exact bytes, and independently checked final totals and
  digests; make overflow or transport failure explicit and fatal.
- [X] Treat every non-agent guest process as invocation membership, kill and
  reap through a process-table-and-pipe-EOF cleanup barrier, and refuse restart
  before cleanup completes.
- [X] Prove an escaped descendant that retains an output descriptor is killed and
  reaped by the guest-wide barrier, and that a first invocation's root mutations
  are absent from a second invocation. Whether those facts are enough to satisfy a
  later recovery assertion is evaluated with the Phase 3 scenario checker.
- [X] Keep application protocol interpretation and assertions in the host
  scenario checker; limit the guest agent to generic process and byte facts.

* Phase 3 — Scenario and passive replay integration
:PROPERTIES:
:STATUS: DONE
:END:

- [X] Run the same acceptance fixture from standalone binary and OCI sources
  through the shared guest runtime.
- [X] Run the focused dynamically linked OCI fixture from its in-image loader and
  library closure and passively replay it.
- [X] Materialize a process termination and restart in the seeded choice plan and
  evaluate ordered process safety, cleanup, fresh-root, and recovery properties.
- [X] Drive the live workload exclusively through recorded input commands and
  derive response-integrity assertions from ordered output frames in the host
  checker before process exit.
- [X] Make workload-originated application traffic traverse the RFD 2 NIC and
  observe the bounded peer-specific outage and restoration.
- [X] Record each source form and passively replay it twice without live source,
  registry, daemon, host mount, or fixture interaction.
- [X] Compare normalized events, assertions, workload-output identities, and
  semantic outcome digests on every replay.
- [X] Reject independently changed workload, launch, cache, scenario, and
  network identities before QEMU starts.
- [X] Require raw source evidence on replay even when a valid derived cache entry
  exists, and recheck selection and stored-layer-to-DiffID relationships before
  reusing that entry.
- [X] Preserve intentional output corruption as a failing safety assertion and
  nonzero CLI result for both source forms.
- [X] Enforce runtime overlay compatibility during assembly and replay, so a
  package entry that collides with the overlay, or a launch path that overlay
  replacement invalidates, is refused before a template is published instead of
  at the runtime boundary.
- [X] Separate owner-only replay closure and optional bounded output bytes from
  default shareable failure metadata, which contains no environment values or
  stream bytes. The Phase 1 store already publishes owner-only objects, but the
  run-level classification belongs with the run manifest, which this phase owns.
- [X] Harden the phase against the first adversarial review of the stack, with a
  regression test for each finding:
  - [X] Make every divergence, envelope, and parser diagnostic value-free, so a
    shareable failure report names the event kind and its coordinates without the
    recorded launch environment or exact stream bytes.
  - [X] Publish the guest image cache owner-only (0700 directory, 0600 entries),
    repair a reused entry's mode, and refuse a non-regular entry.
  - [X] Evaluate per-invocation stream violations, require sequences to start at
    one and stay contiguous, require accepted inputs to advance by their byte
    count as distinct later commands, and require complete stdout lines and no
    stderr bytes at exit.
  - [X] Require the first cleanup barrier to reap the escaped descendant as well
    as the primary, and order termination, exit, cleanup, and the escaped line.
  - [X] Bound the restarted invocation's first answer with the scenario's
    liveness bound so the first invocation cannot satisfy recovery.
  - [X] Match each invocation's next complete response line strictly, so a wrong
    response fails the property instead of blocking until the VM deadline.
  - [X] Track the administrative outage in the driver and restore the network
    before an early shutdown, and make the fake guest enforce the agent's refusal.
  - [X] Wait for the startup line before the first command, drain queued events
    before every process command, and treat a terminal event observed while
    awaiting a response as an orderly end.
  - [X] Bound every command identifier by the last issued command, require
    synchronous acknowledgements to name the awaited command, validate
    input-accepted contents, and restrict the shutdown drain to workload events.
  - [X] Constrain `payload_bytes` to the fixture's hex-encoded token limit and
    preflight the serialized start and input frames in record and replay.
  - [X] Enforce the replay artifact budget on the recorded event stream before
    publication.
  - [X] Assert the intended missing-raw diagnostics and cover a removed
    closure-referenced raw object in the acceptance script.
  - [X] Strengthen the fresh-root witness so the fixture also mutates its own
    executable's mode in the immutable workload root and each invocation reports
    `state value=fresh root=fresh`.
  - [X] Upload only the acceptance report, process status, and shareable failure
    bundles from the Phase 3 diagnostics artifact.
- [X] Harden the phase against the second adversarial review, which rechecked the
  first round and found four fixes incomplete and three new defects:
  - [X] Reduce every parser failure that can reach a diagnostic to a value-free
    form, including TOML type errors and surplus guest frames, and cover both a
    malformed specification and a malformed private artifact with canaries.
  - [X] Fold the lifecycle events of a stopped invocation while awaiting a network
    acknowledgement, because the runtime serializes an exit and its cleanup
    barrier as separate frames.
  - [X] Correlate network acknowledgements with the values the host configured,
    require the agent-stopped acknowledgement to name its command, park
    future-command events only in passive replay, and require the checker to
    account for every accepted input command and the end-of-input state.
  - [X] Preflight the launch-bearing response frame as well as the command, and
    enforce the replay budget on the workload lock and run manifest.
  - [X] Validate a reused cache entry before opening it, so a non-regular entry is
    rejected instead of blocking the hash.
  - [X] End the wait for a response line as soon as the invocation writes to
    stderr, so a failing application that stays alive fails its property instead
    of exhausting the VM deadline.
  - [X] Reconstruct each invocation's stdout before counting fresh-root witnesses
    in the acceptance harness, so a line split across frames still counts.
- [X] Harden the phase against the third adversarial review, which found the
  confidentiality fix bypassable and three further defects:
  - [X] Reduce every parser failure to a location only, including the generic
    frame readers, the retained canonical specification, and the TOML
    specification and scenario parsers, and add canaries whose secret is the
    offending value itself, including one that embeds the parser's delimiter.
  - [X] Validate the asynchronous lifecycle and network events the driver folds
    without an expectation: unknown invocations, duplicate starts, exits,
    cleanups, configurations, activations, and restorations, a cleanup before its
    exit or without a reap, a configuration outside the fixed profile, and an
    activation without its prohibition rule.
  - [X] Bound every published artifact with the same reader the replay path uses,
    so an oversized replay log or diagnostic log cannot be published and then
    rejected on replay.
  - [X] Stop the wait for a response line once its current stdout line exceeds the
    response bound, so an over-long unfinished line fails its property instead of
    exhausting the VM deadline.
  - [X] Require the acceptance harness to observe one fresh-root witness in each
    of the two invocations, counting only newline-completed lines.

* Exit criteria

- [ ] Every acceptance criterion in the RFD has linked automated or captured
  evidence.
- [ ] Binary and OCI inputs converge before the guest runtime boundary.
- [ ] Replay reconstructs workload identity independently and uses no live or
  ambient workload input after QEMU starts; derived cache alone is insufficient.
- [ ] The packaged workload demonstrably owns the process and network behavior
  used by acceptance assertions.
- [ ] The agent exposes only an unprivileged child chroot and generic protocol;
  the dedicated VM remains the host security boundary.
- [ ] The implementation preserves RFD 1 and RFD 2's VM adapter, replay,
  artifact, and normalization ownership boundaries and documents the intentional
  host-only refinement for workload-specific assertions.
- [ ] No registry runtime, container daemon, host mount, second workload,
  persistent disk, richer fault model, or exploration engine exists without new
  evidence and an RFD.
