= Deterministic guest time model

SimFerret pins the guest's QEMU time model so that the passage of time inside the
guest is a reproducible function of the fixed VM configuration and the work the
guest performs. This page is the entry point for that investigation: it maps each
artifact to what it records and gives the command that reproduces the
measurements. Current progress lives in the implementation checklist, not here.

== Reproducing a measurement

[source,shell]
----
SIMFERRET_ICOUNT_OPTIONS=shift=N,sleep=off \
SIMFERRET_TIME_MODEL_OUTPUT=<directory> \
.agents/dev ./scripts/time-model-probe.sh
----

The harness writes `evidence.txt` with the configuration, the per-run status,
duration, and replay-log size, and prints the measurements it compared. Raw
per-run serial output and replay logs stay in the output directory, which defaults
to the untracked `.poc/time-model-probe` tree. `SIMFERRET_TIME_MODEL_RUNS` and
`SIMFERRET_QEMU_TIMEOUT` adjust the run count and the per-run deadline.

== What the investigation established

* Under the default `shift=auto`, the same fixed computation measured 42.65 ms and
  126.05 ms of virtual time in two runs while returning the same result, a
  deadline decision flipped between runs in the unsupported
  `shift=auto,sleep=off` combination, and the replay log differed in every run.
* Pinning the scale and disabling host-paced idle advancement made every measured
  value exact across five complete runs at `shift=2`, `shift=3`, `shift=4`,
  `shift=5`, and `shift=7`; the pinned value is recorded with its reason in the
  evidence above.
* The pinned scale is a semantic choice about an artificial performance model, not
  a correctness choice: the validated window is flat in reproducibility, and
  timeout-sensitive results are conclusions about the chosen model rather than
  predictions of production timing.
* Time, entropy, and ordering fault injection remain unimplemented, and the
  arrival timing of live host input has no deterministic position in guest virtual
  time; both are separate work.
